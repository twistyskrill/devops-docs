# Журнал типовых инцидентов

| Инцидент | Наблюдаемый признак | Источник диагностики |
| --- | --- | --- |
| Неиспользуемая переменная | Красная проверка `pylint` в PR | Static analysis |
| Недостаточные права публикации | `build` успешен, `deploy` не получает OIDC-токен | Deploy to GitHub Pages и блок `permissions` |
| Битая ссылка | `mkdocs build --strict` завершается ошибкой | Build documentation |
| Старая версия после успешного деплоя | Зелёный workflow, прежнее содержимое в браузере | URL окружения, время публикации и кэш браузера |

## Правило разбора

Укажите симптом, затронутый компонент, доказательство из журнала, причину, исправление и результат проверки восстановления.
